# Worcon iPhone

Worcon iPhone is a native SwiftUI app. The source project is in [`Worcon/`](Worcon/README.md), with the Xcode project at `Worcon/Worcon.xcodeproj`. Its minimal Groq proxy is in [`Worcon/backend/`](Worcon/backend/DEPLOY.md).

The original Worcon website is maintained separately in [yaqihu821-ux/worcon](https://github.com/yaqihu821-ux/worcon). Keep Groq API keys and service access tokens out of this repository.
